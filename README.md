# 🪐 DIY Pocket Wireless KVM

基于两块 **ESP32-C3 SuperMini** 与 **CH9329** 串口键鼠协议芯片打造的免驱口袋无线 KVM 控制线。

**核心特性：**
- 🖱️ **PiKVM 级全局无感锁鼠拦截** — Pointer Lock API + 相对/绝对坐标双模
- 📡 **ESP-NOW 动态变长无线物理隔离** — 键盘 14B / 相对鼠标 11B / 绝对鼠标 13B 智能分帧
- 🔌 **BIOS 级秒控** — CH9329 硬件 HID 翻译，免驱直通
- 💰 **极低成本** — 两块十几元的 SuperMini 板卡即可完工

## 硬件要求

### 核心元器件

| 物料 | 规格 | 数量 | 用途 | 参考成本 |
|:---|:---|:---:|:---|:---|
| ESP32-C3 SuperMini | RISC-V 单核，带 ESP-NOW | **2 块** | A 面发射端 + B 面接收端 | ~¥11/块 |
| CH9329 串口转 USB HID 模块 | 支持键盘+鼠标复合模式 | **1 块** | B 面接收端，将串口数据翻译为标准 USB HID | ~¥5/块 |
| Type-C 数据线 | 需支持数据传输（非纯充电线） | **1 根** | 发射端 A 连接主控 PC/Mac | — |
| 细导线 / 杜邦线 | - | 若干 | 接收端 ESP32-C3 与 CH9329 连接 | — |

> *注：可选焊接/杜邦线连接，焊接需要动手能力，杜邦线会增大体积*

### 工具与软件环境

| 类别 | 要求 |
|:---|:---|
| 焊接工具（可选） | 电烙铁、焊锡丝、助焊剂 |
| 固件烧录 | [Arduino IDE](https://www.arduino.cc/en/software) 2.x，需安装 `esp32` 开发板支持包 |
| Arduino 板级设置 | `Tools → Board` 选 **ESP32C3 Dev Module**；`USB CDC On Boot` 设为 **Enabled** |
| 浏览器 | 支持 [Web Serial API](https://developer.mozilla.org/docs/Web/API/Web_Serial_API) 的 Chromium 内核浏览器（Chrome / Edge 89+） |
| 3D 打印机（可选） | 可找代打或者不使用外壳 |

### ESP32-C3 SuperMini 选购注意

- 确认板载 **USB Type-C** 接口（非 Micro-USB），且支持**数据通信**
- 确认引出的引脚包含 **GPIO 20 (RX)、GPIO 21 (TX)、GND、5V/VCC**
- 如果没有焊接工具，建议购买已焊排针版本

### CH9329 模块选购注意

- 确认模块带有 **CFG1、CFG0、MODE1、MODE0** 四个跳线帽引脚（部分精简版缺失）
- 默认发货状态下跳线帽应处于**拔除/悬空**状态（高电平），收到后请勿插入跳线帽

## 硬件准备与接线

### 1. 架构概览

```
┌──────────────┐     Web Serial      ┌──────────────────┐   ESP-NOW    ┌──────────────────┐     USB HID     ┌───────────────┐
│  主控 PC/Mac  │ ──────────────────► │  发射端 ESP32-C3  │ ──────────►  │  接收端 ESP32-C3  │ ──────────────► │  目标 Windows │
│  (浏览器)     │    Type-C 数据线     │                  │   射频        │  + CH9329        │   USB 插入主板   │   被控电脑     │
└──────────────┘                     └──────────────────┘              └──────────────────┘                 └───────────────┘
```

### 2. 获取 ESP32-C3 的 MAC 地址

在烧录发射端固件之前，必须先获取**接收端 ESP32-C3** 的物理 MAC 地址，用于建立 ESP-NOW 射频绑定。

1. 在 Arduino IDE 中打开 [`arduino/get-mac.ino`](arduino/get-mac.ino)，烧录到**接收端 ESP32-C3**（暂时不接 CH9329）
2. 打开串口监视器（波特率 `115200`），会看到类似输出：

```
=========================================
💡 这块 ESP32-C3 的 MAC 地址为: F0:08:D1:2E:7A:EC
=========================================
```

3. 记录 MAC 地址，后续需要填入 [`arduino/tx.ino`](arduino/tx.ino) 的 `broadcastAddress` 数组中

> 💡 板载 LED 会规律闪烁，代表程序运行成功。

### 3. A 面：发射端

| 组件 | 说明 |
|------|------|
| 主控 | ESP32-C3 SuperMini × 1 |
| 接线 | **不接任何外部引脚**，仅用 Type-C 数据线连接 PC/Mac，通过 Web Serial 接收浏览器指令 |

### 4. B 面：接收端（背靠背翻转焊接 / 杜邦线连接）

将 CH9329 模块与接收端 ESP32-C3 SuperMini 连接：

| ESP32-C3 引脚 | → | CH9329 引脚 | 说明 |
|:---|:---:|:---|:---|
| **GPIO 21 (TX)** | → | **RX** | 单片机发送，CH9329 接收键鼠十六进制流 |
| **GPIO 20 (RX)** | → | **TX** | 单片机接收（留作状态返回与自检） |
| **GND** | → | **GND** | **必须共地**，确立串口高低电平基准电压 |
| **5V / VCC** | → | **5V / VCC** | 由被控端 Windows 主板供电 |

> ⚠️ **跳线帽状态**：CH9329 模块上的 **CFG1, CFG0, MODE1, MODE0** 四个引脚必须全部保持**拔下、悬空（高电平 1）**状态，芯片才会默认开启串口协议传输模式。

## 固件烧录

> **编译前提**：Arduino IDE 中 `工具 (Tools) → USB CDC On Boot` 必须切换为 **`Enabled`**。

### A 面：发射端固件

烧录 [`arduino/tx.ino`](arduino/tx.ino) 到发射端 ESP32-C3。采用**异步非阻塞轮询 + 变长编码智能分切**架构，彻底杜绝看门狗死锁。

> ⚠️ 烧录前，将第 4 行 `broadcastAddress` 替换为你之前查到的接收端 MAC 地址。

### B 面：接收端固件

烧录 [`arduino/rx.ino`](arduino/rx.ino) 到接收端 ESP32-C3。开机时通过 `0x09` 命令强制将 CH9329 写为**工作模式 0x00（键盘 + 全功能鼠标复合模式）**，并在 `onDataRecv` 中实现纯净变长无损放行。

> ⚠️ **开机关键步骤**：烧录完成后，必须将接收端从 Windows 上**彻底拔掉，等待 3 秒后再重新插回**。设备管理器应出现 `1 个键盘 + 1 个符合 HID 标准的鼠标`，无黄色感叹号。

## 网页控制台

[`html/index.html`](html/index.html) 是部署在云服务器上的最终控制台页面，融合 **Pointer Lock API 全屏锁鼠** 与 **33.3ms 前端限流消噪状态机**，实现 VNC 级无感跨屏控制。

> 支持：原生大写字母、Command→Ctrl 映射、Ctrl+Alt+Del 等宏按键、相对鼠标丝滑跟手。

## 联调测试

### 1. 设备自检

- 发射端插入 PC/Mac USB 口，接收端插入目标 Windows。
- 检查 Windows **设备管理器**，确认出现 `1 个键盘 + 1 个符合 HID 标准的鼠标`，无黄色感叹号。

### 2. 连接握手

- 在 PC/Mac 上打开部署好的 [`html/index.html`](html/index.html) 控制台网页。
- 点击 **连接发射端硬件**，在浏览器弹窗中勾选 `ESP32-C3` 串口并授权。

### 3. 锁鼠托管（VNC 跨屏）

- 点击页面中央黑色控制区域，PC/Mac 鼠标指针隐形并被锁定。
- **键盘连击测试**：在 Windows 记事本中快速交替敲击 `ab` 或连按 `aaa`，验证精准输出、无粘连。
- **组合键测试**：`Command (⌘) + A` → 目标机全选；`Shift` + 字母 → 大写输出。
- **鼠标测试**：正常移动物理鼠标，目标机光标丝滑跟手，无漂移、无中心弹回。

### 4. 一键回城

- 按下 `ESC` 键，鼠标锁解除，键鼠瞬间回到 PC/Mac 本地。

## 故障排查

| 故障现象 | 根源诊断 | 排查动作 |
|:---|:---|:---|
| **键盘丝滑，鼠标一动不动，蓝灯不闪** | 数据包长度或命令字在发射端被过滤 | 检查 `index.html` 打包函数：相对鼠标命令字 `0x05` / 长度 `11B`；限流 `33.3ms` |
| **键盘完美，鼠标蓝灯闪但光标不动** | 芯片通电时未成功改写 EEPROM 鼠标通道 | 拔下接收端，等 5 秒，换到机箱背后**主板原生 USB 3.0 接口**重新冷启动 |
| **黄色感叹号 ⚠️ / 未知设备** | Windows 残留旧驱动缓存冲突 | 设备管理器 → 右键卸载设备（勾选删除驱动）→ 重新插拔 |
| **高频打字出现幽灵连发** | 击键重复速率与串口带宽并发死锁 | 确认 `USB CDC On Boot = Enabled`；确认固件使用异步非阻塞 `Serial.read()` |
| **杜邦线/飞线连接时功能断续** | 线路阻抗大、未共地导致电气毛刺 | 更换优质纯铜飞线；**确保 GND 共地焊死** |
